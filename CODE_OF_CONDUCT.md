# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, no harassment, no personal attacks, no discrimination. Criticise code and ideas, not people.

Report unacceptable behaviour to **silentbob@silentbob.cz**. Reports are handled confidentially. The maintainer may remove comments, issues or contributions that break these rules and may block people who keep doing it.
