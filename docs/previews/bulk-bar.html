Bulk actions next to APPLY

Today, as soon as one mod is checked, the whole bar under the list is replaced by the bulk actions and APPLY CHANGES is gone. A user who checked a mod by accident (Ctrl+click, Shift+click, Ctrl+A) cannot apply, and JACK IN in the left panel stays locked because the changes are not applied. The proposal: the bar keeps its shape and only the row of small tools changes. The status line and APPLY stay where they are.

  • The four bulk actions keep their colours but become small buttons (26 px instead of 32 px), so the row fits next to APPLY.
  • REFRESH and the other tools are away while mods are checked; F5 still refreshes. Esc or Clear (Esc) brings them back.
  • No sentence explaining where APPLY went: it never leaves.
  • The height of the bar does not change, so the list does not jump when the first mod is checked.
