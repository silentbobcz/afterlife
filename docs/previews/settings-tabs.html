Nexus Mods

PREMIUM

OFFLINE EDITION · NO API KEY · NO CONNECTION TO NEXUS MODS

This is AFTERLIFE Offline: it does not connect to Nexus Mods and needs no API key. Downloads, updates and collections from Nexus Mods come once Nexus Mods registers AFTERLIFE. Until then download mods on nexusmods.com with Manual download and drop them into the window.

ACCOUNT

Your personal API key from your Nexus Mods account (Settings → API Keys). It is stored encrypted for your Windows user and only sent to api.nexusmods.com.

Comes with the full edition, once Nexus Mods registers AFTERLIFE.

ON ITS OWN
FULL READ
Read every mod in full once in days (0 = never)

Between full reads AFTERLIFE asks Nexus Mods only which mods changed: one request for the whole library. The full read is a safety net; the mods take turns, so about the same number is read every day.

WHY

  • Tabs on the left. About twenty options no longer sit in one long column; each tab fits without scrolling at 1612 × 910 (Updates in Offline is the longest).
  • One size for the dialog. Switching tabs does not move anything. On a large screen the dialog stays the same size, because no tab is long enough to need more.
  • Game and library together. Both are only a folder with two links; on their own they would be two nearly empty tabs.
  • Updates is its own tab. It has five choices and the request count; in Offline it stays visible with a lock, like the other Nexus features.
  • Display and diagnostics apart. Today's section 05 mixed appearance, logs and uninstall; each now has one purpose.
  • Uninstall at the bottom, apart. It is not a setting and should not sit next to a checkbox you click often.
  • Requests in plain sight. Updates shows what your settings cost a day against the Nexus Mods limit; the orange warning appears only when full reads would take more than a tenth of the daily limit (about 2,000 mods read every day). Change the days in the preview to see the line follow.
  • Short facts on the tabs. Kept files shows the total size, Nexus Mods a green dot when the key works, so you see the state without opening the tab.
