// NEW: WHERE A FRESHLY INSTALLED MOD LANDS

Static preview of the design in new-category.md. Every freshly installed mod falls into the block NEW, which stands on top by default, can be moved like any block and hides when it is empty. Pick a state:

MODS
MODVERSIONSTATUSON

WHAT THIS STATE SHOWS

RULES

  • Into NEW: a mod you import or download yourself.
  • Not into NEW: an update of a mod you already have, mods of a collection, mods placed by IMPORT ORDER, FIXER quests, files taken over by SCAN MANUAL MODS.
  • Out of NEW: drag the mod into MODS or a category, or MOVE ALL TO MODS (they go to the end of MODS, where new mods landed until now).
  • Load order: higher loads first, NEW included. Installing a mod never changes the order of the other mods among themselves.
  • Empty NEW is not shown; it remembers its place.
