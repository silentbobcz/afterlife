WHAT YOU SEE

#n is the place in the game’s load order, counted after CORE MODS, top to bottom. Inside MODS the mods without a category come first, then each category.
Dashed rows + cyan line: Better Vehicle Handling is being dragged together with its └ layer (local edits); it will land where the line is.
CORE MODS is locked: no number, no handle. COLLECTION is locked as well; its mods keep their order and are numbered.

WHAT CHANGES COMPARED TO TODAY

  • Today: inside MODS and inside every category the list is sorted by name and the load order cannot be set by hand. A drop inside the same section only shows a message; the only way to move a mod is into another category.
  • New: the list follows the order of the profile. Drag a row (or several checked rows) anywhere inside MODS or a category, or across a category boundary; several rows keep their current order as a group.
  • Numbers: every mod after CORE MODS shows its place (#1, #2 …) in the LOAD ORDER view, the same order the game gets in modlist.txt. The numbers and handles are hidden while the list is sorted for viewing (⇅).
  • Layers: a └ row stays right below its mod, has no handle and no number of its own, and moves with its mod.
  • A→Z in the MODS header and in each category header sorts that one section by name, once, after a confirmation. It touches nothing else; dragging works afterwards. Disabled while the list is sorted for viewing.
  • New mods (import, download) land at the end of MODS, without a category. An update keeps the place of the old version.
  • Existing libraries: the current (alphabetical) order is taken over unchanged.
  • Not changed: CORE MODS and collections, categories as blocks, the ⇅ view sort (view only).
